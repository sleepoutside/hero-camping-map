# 勇者露營‧世界地圖（福爾摩莎島篇）

全台露營熱點本週天氣預報與裝備建議（可搜尋單一營地、分享圖卡），以及魔物情報。

- 營地位置與海拔：觀光署「全台露營場資料」與 OpenStreetMap 補充（© OpenStreetMap 貢獻者，ODbL）
- 頁面上的大雨、強風提醒依預報數字判斷，不是氣象署發布的警特報

熱點依交通部觀光署「全台露營場資料」中營地最密集的鄉鎮選出，依「政府資料開放授權條款－第1版」利用。

天氣預報：Weather data by [Open-Meteo.com](https://open-meteo.com/)（CC BY 4.0），頁面開啟時即時抓取。

資料來源：網路｜資訊僅供參考，請依官方資訊為準
